📌 **SETUP GUIDE (FOLLOW CAREFULLY)**


**1️⃣ Locate your game folder**

* Open the folder where the game was downloaded
* Check that files are present (like `.exe`, data folders, etc.)

**2️⃣ Download WUB (Windows Update Blocker)**

* [https://www.sordum.org/9470/windows-update-blocker-v1-8/](https://www.sordum.org/9470/windows-update-blocker-v1-8/)
* Download and extract it

**3️⃣ Disable Windows Updates**

* Run WUB as **Administrator**
* Select **"Disable Updates"**
* Click **"Apply Now"**
* Make sure it shows updates are disabled ✅

**4️⃣ Open game properties**

* Right-click the game `.exe`
* Click **Properties**

**5️⃣ Take ONE screenshot containing ALL of these:**

* 📂 Game folder
* 🔒 WUB (updates disabled)
* ⚙️ Game properties window

**6️⃣ Upload your screenshot**

* Send the screenshot in the ticket
* Make sure everything is clearly visible ❗
